Приветствую наставник! 
Для того что бы проверить тесты нам необходимо получить токин авторизации. 
Шаг 1.
Зарегестрироватся на YouGile 
Если уже есть акаунт то дальше нам потребуется логин и пароль 
Шаг 2. 
Нам потребуется создать 2 запроса в Postman
1 запрос на получение ID компании, вот ссылка на докуменктацию - https://ru.yougile.com/api-v2#/operations/getCompanies
Тело запроса состаит из: Логина, Пароля, названия компании
В ответе придёт Список компаний пользователя где будет id компании
Шаг 3.
2 запрос на получения токина авторизации, вот ссылка на документацию - https://ru.yougile.com/api-v2#/operations/AuthKeyController_create
Тело запроса состаит из: Логина, пароля, id компании
В ответе придёт key - ключ авторизации (сохраняем его)
Шаг 4. 
VSC в нашей ветке создаём фаил "config.py"
Записываем туда переменную api_token = "наш key из 3-го шага"
Теперь тысты должны работать
